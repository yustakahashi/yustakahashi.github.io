GitHub Pages upload instructions

1. Rename the repository:
   yusuketakahashi.github.io
   -> yustakahashi.github.io

2. Extract this ZIP.

3. Upload index.html to the root of the repository.

4. In GitHub:
   Settings -> Pages
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
   Save

5. Your site should then be available at:
   https://yustakahashi.github.io/
